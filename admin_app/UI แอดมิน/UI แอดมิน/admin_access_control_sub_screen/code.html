ผู้ดูแลระบบ THLotto

คำสั่งผู้บริหาร
dashboard แดชบอร์ด confirmation_number ควบคุมการออกรางวัล trending_up อัตราหวย group การจัดการผู้ใช้ payments รายงานการเงิน history บันทึกระบบ
help สนับสนุน logout ออกจากระบบ
การจัดการผู้ใช้ chevron_right ควบคุมสิทธิ์

สิทธิ์การเข้าถึงของผู้ดูแลระบบ

จัดการการควบคุมการเข้าถึงตามบทบาทและสิทธิ์ที่ละเอียดสำหรับพนักงานผู้ดูแลระบบ การเปลี่ยนแปลงจะมีผลทันที

warning

ประกาศความปลอดภัยที่สำคัญ

การแก้ไขสิทธิ์ผู้ดูแลระบบของคุณเอง (การลดขั้นตัวเอง) เป็นแบบถาวรและไม่สามารถยกเลิกได้ในระบบ หากคุณลบสิทธิ์ "จัดการผู้ใช้" ของคุณโดยไม่ได้ตั้งใจ คุณจะสูญเสียการเข้าถึงหน้าจอนี้ทันที โปรดดำเนินการด้วยความระมัดระวังอย่างยิ่ง
